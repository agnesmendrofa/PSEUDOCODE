Tujuan Pembelajaran (Informatika Kelas IX)

Memahami pengertian dan fungsi pseudocode dalam pemrograman.
Membedakan antara algoritma kalimat deskriptif dan pseudocode.
Memahami struktur dasar pseudocode: BEGIN, INPUT, PROCESS, OUTPUT, END.
Mampu membaca dan menyusun pseudocode sederhana secara tepat.

💡 Contoh-Contoh Pseudocode

Klik tombol ▶ JALANKAN pada setiap contoh untuk melihat simulasi eksekusi baris demi baris!

Contoh 1 — Menampilkan Nama Sederhana

Menerima masukan sebuah nama, kemudian menampilkan nama tersebut kembali ke layar.

BEGIN
INPUT nama
OUTPUT nama
END
Output: -

Contoh 2 — Menghitung Luas Persegi Perhitungan

Menerima masukan panjang sisi, menghitung luas persegi, lalu menampilkan hasilnya.

BEGIN
INPUT sisi
luas ← sisi * sisi
OUTPUT luas
END
Output: -

Contoh 3 — Menghitung Penjumlahan Aritmatika

Menerima dua angka masukan, menjumlahkannya, dan menampilkan hasil penjumlahan.

BEGIN
INPUT a
INPUT b
hasil ← a + b
OUTPUT hasil
END
Output: -

Contoh 4 — Menghitung Keliling Persegi Panjang Geometri

Menerima masukan panjang dan lebar, lalu menghitung keliling bangun datar.

BEGIN
INPUT panjang
INPUT lebar
keliling ← 2 * (panjang + lebar)
OUTPUT keliling
END
Output: -
